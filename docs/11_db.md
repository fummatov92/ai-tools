# 🗄️ Multi-Engine Database & Backup Inspector (`db` module)

The `db` module inspects, queries, and dumps databases across Postgres, MySQL, SQLite, MongoDB, and Redis without requiring heavyweight GUI clients.

## Supported Engines
- PostgreSQL (`--type postgres`)
- MySQL (`--type mysql`)
- SQLite (`--type sqlite`)
- MongoDB (`--type mongo`)
- Redis (`--type redis`)

## Commands

### 1. Inspect SQL Dump / Database
```bash
ai-tool db inspect /path/to/backup.sql
ai-tool db inspect --type postgres
```
Extracts table names, row estimates, columns, primary keys, and total dataset size in 0 tokens.

### 2. View Table Structures
```bash
ai-tool db tables /path/to/database.sqlite
```

### 3. Fast SQL Querying
```bash
ai-tool db query "SELECT count(*) FROM users" /path/to/backup.sql
```

### 4. Create Database Dump
```bash
ai-tool db dump --type postgres --output backup.sql
```
